# Проект: Робособака на кабестановых редукторах

Этот репозиторий документирует полный процесс проектирования, сборки и программирования робота (робособаки). 

Основная цель проекта — создать функциональную и динамически стабильную платформу, используя доступные компоненты и открытые технологии. Особенностью конструкции являются **кабастановые редукторы** (Capstan Drive), обеспечивающие высокий крутящий момент и практически полное отсутствие люфта.

### Ключевые технологии:
*   **Привод:** Бесколлекторные двигатели (BLDC)
*   **Драйверы:** ODrive
*   **Редукторы:** Кабастановые (Capstan Drive)
*   **Основной контроллер:** **Teensy 4.1**
*   **ПО:** **C++** в среде **PlatformIO** для основного кода, **Python** для тестов и калибровки.

**Текущий этап:** Настройка и тестирование привода одного сустава.
*   ✅ Низкоуровневый тюнинг ПИД-контроллера завершен.
*   ✅ Достигнута высокая точность и стабильность позиционирования под нагрузкой.
*   ✅ Разработаны и отлажены скрипты для динамических тестов.
*   ✅ Собрана кинематика одной ноги робота с абдукцией.
*   ✅ Разработана управляющая программа для ESP32-C3 по реализации шага (кривая Безье).
*   ✅ Реализована логика пересчета шага и крена по оси Z по гироскопу.

## Структура репозитория

Репозиторий организован для охвата всех аспектов проекта, от аппаратного обеспечения до программного кода.

```
/
├── hardware/               # Все, что касается "железа"
│   ├── cad/                # CAD-модели (исходники, STL, STEP)
│   ├── electronics/        # Электрические схемы, дизайн печатных плат
│   └── bom/                # Bill of Materials - списки всех компонентов
│
├── software/               # Весь программный код
│   ├── firmware/           # Низкоуровневый код и конфигурации
│   │   ├── odrive_config/  # Сохраненные конфигурации ODrive (.json)
│   │   └── python_tests/   # Тестовые и калибровочные скрипты Python
│   │
│   ├── teensy_ws/          # <<-- Основная рабочая область (проект PlatformIO)
│   │   ├── include/        # Заголовочные файлы C++ (.h)
│   │   ├── src/            # Исходный код C++ (.cpp)
│   │   ├── lib/            # Внешние библиотеки
│   │   └── platformio.ini  # Файл конфигурации PlatformIO
│   │
│   └── simulation/         # Файлы для симуляции (URDF-модели и т.д.)
│
├── docs/                   # Документация и медиафайлы
│   ├── media/              # Фото, видео, GIF процесса сборки и работы
│   ├── assembly/           # Инструкции по сборке
│   └── research/           # Полезные статьи, расчеты, заметки
│
├── .gitignore              # Игнорирование временных файлов IDE, логов и т.д.
├── LICENSE                 # Лицензия проекта
└── README.md               # Этот файл
```
