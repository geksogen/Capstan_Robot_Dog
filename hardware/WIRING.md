# 🐕 3D-Leg Module: Руководство по распиновке и подключению

В данном документе приведено полное описание электрических соединений и схемы распиновки для одного **3D-стабилизированного модуля ноги** робособаки. Система построена на базе микроконтроллера **ESP32-C3 Super Mini**, драйверов моторов **MKS ODrive Mini** (шина CAN) и высокоточного 9-осевого датчика **SparkFun VR IMU BNO086**, подключенного по шине I2C с аппаратными прерываниями.

---

## 📌 1. Аппаратная архитектура контроллера

Сердцем логики является плата **ESP32-C3 Super Mini** (одноядерный RISC-V @ 160 МГц). Из-за особенностей встроенного USB-стека чипа, при прошивке в IDE обязательно должен быть включен параметр **"USB CDC On Boot: Enabled"** для сохранения стабильного Serial-соединения.

## 🤖 3. Конфигурация приводов (Сеть шины CAN)

Все три драйвера **MKS ODrive Mini** подключаются параллельно к высокоскоростной дифференциальной шине CAN.

### Сигнальные и силовые линии шины:
* **Линия CAN_H:** SN65HVD230 `CAN_H` ─── ODrive 0 `CAN_H` ─── ODrive 1 `CAN_H` ─── ODrive 2 `CAN_H` Black провод
* **Линия CAN_L:** SN65HVD230 `CAN_L` ─── ODrive 0 `CAN_L` ─── ODrive 1 `CAN_L` ─── ODrive 2 `CAN_L` Red провод
* **Сигнальная земля:** Логический `GND` драйверов ODrive (или клемма питания `DC -`) **ОБЯЗАТЕЛЬНО** должны быть соединены с общим `GND` контроллера ESP32-C3 для выравнивания потенциалов и устранения земляных петель.

### Адресация узлов и параметры (Маппинг в `odrivetool`):
1. **NODE_ID 0 (Левый мотор плеча):**
   * Настроен в режиме фильтрации положения (`input_mode = 3`).
   * Направление вращения инвертировано программно/физически с учетом навивки кабелей редуктора.
2. **NODE_ID 1 (Правый мотор плеча):**
   * Базовая опорная ось для генерации плоских траекторий Безье.
3. **NODE_ID 2 (Мотор абдукции / Abad Joint):**
   * Активирован абсолютный SPI-эндокер с сохранением калибровки.
   * В код зашито постоянное смещение на 10 градусов вправо (`0.17453` рад) для компенсации люфтов редуктора при старте.

> ⚠️ **Важно:** Активируйте согласующий **резистор 120 Ом** (джампер или переключатель) строго на самой последней плате ODrive, которая физически завершает линию CAN-шины.

## 🛠️ 4. Настройка датчика стабилизации (Ориентация BNO086)

Модуль **SparkFun SEN-22857 (BNO086)** распаивается жесткими одножильными проводами напрямую к контактным площадкам для защиты от постоянных ударных нагрузок и вибраций при ходьбе робота.

* **Физический адрес I2C:** `0x4B` (Транспортный уровень Hillcrest Labs SHTP).
* **Режим работы:** Активирован вектор `Game Rotation Vector` на частоте **100 Гц**. Данный режим использует только гироскоп и акселерометр, что полностью исключает «плавание» углов от мощных магнитных полей, создаваемых BLDC моторами робособаки.
* **Связь с кинематикой:**
  * Угол `Roll (Крен)` корректирует позицию мотора `NODE_ID 2` для компенсации бокового завала корпуса.
  * Угол `Pitch (Тангаж)` вносит тригонометрическую поправку \(X = Z \cdot \tan(\theta_{\text{pitch}})\) в координату `X` плечевых моторов, смещая стопу вперед-назад для удержания продольного баланса робота.
